```Python
import asyncio
loop = asyncio.new_event_loop()  # イベントループ作成

asyncio.set_event_loop()  # イベントループを現在のスレッドに紐づける

current_loop = asyncio.get_event_loop()  # 該当スレッドのイベントループを取得

loop.run_forever()  # イベントループを起動
loop.stop()  # イベントループを停止
```

run_foreverメソッドは、_run_onceメソッドを繰り返し実行する無限ループになっている。
loop.stop()を実行しないと永遠に実行される。

```Python
def run_forever(self):
    """Run until stop() is called."""
    while True:
        self._run_once()
        if self._stopping:
            break
```

_run_onceメソッド内で管理される三つのキュー
・Readyキュー: 「今すぐ実行可能なタスク」が格納されるキュー。
  call_soonでコールバックを登録する

・Scheduled キュー: 「未来の指定時刻に実行されるタスク（タイマー）」が格納されるキュー。
  call_laterでコールバックを登録する

・I/O イベント待ちリスト: I/O操作（ネットワーク通信やファイル読み書き）の完了待ちリスト。
  add_writer, add_readerでコールバックを登録する
