非同期処理の場面では、開始した後に将来のある時点になって初めて完了するタスクが数多く存在します。

このロジックを表現するために、Pythonは Future クラスを実装しています。

Future クラスは、「将来完了することになる非同期タスク」を表現するものです。

```Python
import asyncio

loop = asyncio.new_event_loop()  # 新しいイベントループを手動で作成する
fut = loop.create_future() # イベントループに紐づいた空のFutureオブジェクトを作成する

fut.set_result("result")  # Futureに結果("result")をセットし、「完了状態」にする
print(fut.done(), fut.result())

fut.set_exception(TypeError("Type Error"))
print(fut.done(), fut.exception())

fut.cancel("cancel...")

def on_done(f: asyncio.Future) -> None:
  try:
    print(f"Futureの結果: {f.result()}")
  except Exception as e:
    print(f"Futureエラー: {e}")

fut.add_done_callback(on_done)  # Futureが完了した際に実行する関数を登録する
```
